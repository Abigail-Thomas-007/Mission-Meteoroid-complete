# Mission-Meteoroid
## Project Option
Website
## Project Description
My project is an interactive site that functions as a mission briefing. Users or players will find themselves on a sleek site with options to sort through the information needed for their mission. They expand and collapse information paragraphs and open connected pages with more detailed descriptions of different places, things, or creatures they are expected to encounter. This experience allows the user or player to feel as though they have been recruited into an exclusive mission with high stakes.
## Theme Interpretation
My project responds to the theme of Space as it is an interactive mission briefing revolving around the idea of prepping astronauts for space travel and alien worlds.
## Intended User or Player
This project was designed with younger-aged teens in mind, hoping to inspire them to learn more about planets. However, this site is friendly for all ages. 
## User or Player Goal
The user or player should be able to learn about a fictional planet and its creatures and navigate an interactive storyline. 
## Main Features
Mission statements, overview, and task list
Planet information regarding plants, animals, and other elements that may be useful to the agent (user)
Company overview and customizable agent profile
Checklist to fully navigate the site and its sections
## JavaScript Features
JavaScript is used to toggle elements and tasks. JavaScript is used to manage a completion tracker for the 'Mission Status' section. JavaScript is used to create feedback with completion messages. JavaScript is used to create a personalized Agent message. 
## Responsive Design
Text, cards, and sections shift to better fit when screen sizes change. They will stack or reshape as necessary. 
## User Testing
In this feedback from testers, it was commonly expressed that overall navigation was understood fairly easily. However, there was some confusion over if tasks had been completed. Interactions with how multiple buttons took you to the same page were also found to be confusing. It was also mentioned that how the site adjusts to smaller screens should be changed to feel more uniform with the original page. One suggestion that was repeated from my testers was how my navigation bar should be able to move different paragraphs to the top of the screen.
## Revisions
After testing, I updated the task bar so the tasks would cross out. I also added images, adjusted sections to become cards, and created a checklist. Another adjustment that was completed after testing was scrolling so that selected paragraphs moved to the top of the page.
